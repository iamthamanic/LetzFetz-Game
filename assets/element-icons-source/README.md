# Element icon PNGs

Transparent PNGs live in **`public/icons/elements/`** — same as `public/brand/letz-fetz-logo.png`.

| Datei | Element |
|-------|---------|
| `fire.png` | Feuer |
| `water.png` | Wasser |
| `earth.png` | Erde |
| `air.png` | Luft |
| `shadow.png` | Schatten |
| `light.png` | Licht |

## Aktualisieren

1. Export aus Figma/Photoshop als **PNG mit Transparenz**.
2. Dateien direkt nach `Letzfetzprototype/public/icons/elements/` kopieren (Finder), **nicht** per Chat-Bild — Uploads verlieren oft den Alpha-Kanal.
3. Dev-Server neu laden.

Optional: Originale in `assets_ui/` oder hier als Backup ablegen.
